## Drop arithmetic

Lengths 2, 3, 4, 5 drop 1, 2, 2, 3 pearls respectively. Drops follow the body where it dies, not the intended end of a failed sprint.

## Inference

If deliberately sacrificing a dragon, estimate which side can collect each drop and whether the sacrifice ends the game. Odd lengths have a slightly better fractional recovery, but there is no demonstrated profitable recycling loop.

A missing action is not a wait command. See the timeout conflict in the master.
