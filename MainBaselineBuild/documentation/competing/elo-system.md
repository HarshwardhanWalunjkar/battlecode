## Submission identity

Identical file contents count as identical code regardless of ZIP timestamps, compression, wrapper folder, or ignored metadata/cache entries. A changed comment is different code, but still subject to the 12-hour rule. Among identical prior bots, the highest count is inherited. Pre-rule submissions have legacy handling; consult the source for historical accounts.
